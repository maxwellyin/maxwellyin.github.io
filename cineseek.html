Retrieval System

Search movies by meaning, not keywords.

CineSeek is a semantic movie search system designed to show the full retrieval engineering loop: dataset preparation, dual-tower training, FAISS indexing, low-latency serving, and optional LLM-based reranking.

System Snapshot

Retrieval-first architecture, with an optional LLM agent.

The system keeps retrieval explicit and measurable: sentence embeddings, a lightweight dual-tower model, FAISS nearest-neighbor search, and an optional agent layer for rewriting, reranking, and explanation.

What It Does

Built for fuzzy natural-language movie queries.

CineSeek maps user intent to relevant titles rather than relying on exact keyword overlap. It is trained on real query relevance data and structured so retrieval remains the core system primitive.

Semantic Search

Queries and movies are projected into a shared space so the system can retrieve meaningfully related titles beyond surface text overlap.

Fast Retrieval

FAISS serves top-k nearest neighbors with low latency, making the stack usable as an interactive product rather than just an offline experiment.

Agent Refinement

An optional LLM agent rewrites vague queries, reranks the shortlist, and produces short summaries without replacing the retrieval layer itself.

Request Path

How a query moves through the system

user query
  -> sentence-transformer embedding
  -> query tower
  -> FAISS retrieval over item embeddings
  -> top-k candidates
  -> optional LLM agent (rewrite / rerank / explain)
  -> final results
Engineering Scope

This is a retrieval system, not a prompt wrapper.

The project is structured to demonstrate an end-to-end retrieval workflow: prepare a labeled dataset, cache text embeddings, train a lightweight retriever, build an ANN index, expose a search interface, and then layer LLM assistance on top as a controlled enhancement.

Tech Stack

Core components

Modeling

PyTorch, Sentence-Transformers, dual-tower retrieval, cached embeddings.

Serving

FAISS for ANN search, FastAPI for the demo service, static project page on GitHub Pages.

Agent Layer

LangChain with Gemini, OpenAI, or Ollama for reranking and explanation.
